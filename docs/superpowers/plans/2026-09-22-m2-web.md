# M2 · Web 全量 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** billguard-web 成为功能完整的 BillGuard Web 应用:Spring Security 三件套(令牌认证/同源 CSRF/能力门禁)、PBKDF2 登录与 Redis 节流、账单域全量(CSV 导入/总览/对比/四类异常/分类规则/工作流/订阅/报告/导出/清空)、chat 与审批决策编排(Redis 会话锁 + LLM 槽位)、前端三件接入、Micrometer 指标端点。

**Architecture:** `web(Facade/Controllers) → 认证(Authenticator + Spring Security 过滤器) → 账单域(BillRepository, JdbcTemplate) → agent-runtime(引擎)`;chat 编排复用 M1 的 RedisSessionLock/RedisLlmLimiter/PgApprovalStore;LLM 生产实现 SpringAiLlmClient 在 LlmClient 接口后。

**Tech Stack:** M1 基础 + spring-boot-starter-security + spring-ai-starter-model-openai + Micrometer(Boot 自带)。

**Spec:** `docs/superpowers/specs/2026-09-22-java-agent-runtime-design.md` §6(Web 层与安全)

## Global Constraints(M1 全部沿用,新增)

- Python 参考源:web.py / auth.py / bills.py / agents/bills.py / coordination.py / metrics.py(D:\shixi\aicoding\feedback-agent-runtime\billguard\)
- **错误消息逐字**:登录失败统一「用户名或密码错误」;CSRF「跨站请求被拒绝」;能力「当前角色无权执行此操作」;锁 423「另一会话操作正在进行,请稍后重试」;忙 429「服务繁忙,请稍后重试」;未登录 401「未登录或会话已失效」/「登录已过期,请重新登录」
- Cookie:`session=<token>; HttpOnly; SameSite=Strict; Path=/; Max-Age=604800`(+Secure 当 `BILLGUARD_SECURE_COOKIES`∈{1,true});登出 Max-Age=0
- 用户名规则 `^[a-z0-9][a-z0-9_-]{1,31}$`,密码 ≥8;PBKDF2-HMAC-SHA256 200k 迭代 16B salt;未知用户名跑等代价 dummy 哈希;恒时比较 `MessageDigest.isEqual`
- 能力表(per-web.py `_CAPABILITY_BY_PATH` 16 条)与角色能力(user: report_write/bills_write/approval_decide;admin: +users_manage)逐字
- 同源校验:Origin 优先 Referer 兜底,任一存在则 netloc(小写)须等于 Host;两者都缺放行
- 登录节流:键 `login:fail:{sha256(user|ip)}`,5 次/600s,成功清零;IP 取 `X-Real-IP` 缺省远端地址
- 账单域多租户:owner 子句三态(owner=''→IS NULL;'admin'→owner=? OR IS NULL;其他→owner=?),admin 视野含存量 NULL 行
- Tomcat 有界:`server.tomcat.threads.max=16 / accept-count=32`
- 前端三件原样拷贝 PY `billguard/web_static/` → `resources/static/`(path traversal 由 Spring 静态资源处理,无需自写)
